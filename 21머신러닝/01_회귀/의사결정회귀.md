## 의사결정 회귀

- Position_Salaries.csv실습
- 샘플이 적어서 모델 성능 평가 제한적임
- 과적합, 규칙기반 예측 , 비선형 관계 실습 적당함.

1. 데이터 분석

- 입력(feature) : 직급단계 10단계
- 출력(정답, label, target) : salary(연봉)
- 특징 : level이 올라갈 수록 salary가 선형이 아니라 급격히 증가(비선형/계단형) 함.
  - 트리 모델은 어느 구간에서 얼마로 나눌지 고민(스스로 찾는 방식)
  - 이 데이터는 계단 형태 예측이 자연스럽게 연출이됨.

2. 실습목표

- 구간을 나누고 평균값을 통해서 예측하는 의사결정 나무 원리를 이해할 수 있다.
- 과적합/과소적합을 조절할 수 있다.
- 선형회귀 vs 다항회귀 vs 트리회귀 예측 형태가 어떻게 다른지 비교할 수 있다.
- MSE 로 모델을 평가하고 작은 데이터에서 평가가 왜 흔들리는지를 직접 목격해 본다.

3. 알아야 하는 개념

- 회귀 : 연봉처럼 숫자를 예측하는데 사용됨
- 의사결정 나무 : 각 구간(리프)의 평균 연봉을 예측값으로 사용한다.
- 과적합 : 깊이가 너무 크면 계단이 촘촘해짐.
- 하이퍼파라미터
  - max_depth : 트리 깊이 제한(클수록 복잡)
  - min_samples_leaf : 리프에 최소 몇 개 샘플 유지(클수록 완만)
- 평가지표
  - MSE : 큰 오차에 더 민감
  - R2결정계수: 설명력( 1에 가까울 수록 좋음 - 결과값이 적을 수록 좋은 결과라고 말할 수 있음 )

4. 질문

- 레벨6과 레벨7 사이(6.5)는 어떤 연봉이 합리적일까?
  - 선형/다항식/트리 모델이 각각 다른 답을 내고 결과 토론
- max_depth = 1,2,3,None
  - 너무 단순(과소적합) <-> 너무 복잡(과적합) 비교
- min_sample_leaf=1,2,3 바꾸며
  - 리프에 최소 샘플 수를 강제하면 계단이 어떻게 완만해지는지 관찰해 보다.
