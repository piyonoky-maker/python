## 가상 환경 생성
### 왜 가상환경인가?
- 프로젝트마다 필요한 라이브러리 버전이 다르다.
- 가상환경이면 pip install한 패키지가 서로 섞이지 않아서 충돌이 적다.
- 프로젝트 폴더 + 가상환경 + requeirements.txt

#### 프로젝트 생성하기
```sh
cd 프로젝트이름 상위 폴더
python -m venv 프로젝트명
cd 프로젝트명
cd Scripts
# 가상 환경 활성화
activate.bat
```

### 패키지 설치
```sh
# pip 업드레이드
python -m pip install --upgrade pip

# pip install requests
```
